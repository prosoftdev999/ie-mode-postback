`client/` is the entry desk client's install folder as it stood on the workstations: three screens, `import.html`, `export.html` and `amend.html`, with their stylesheet and scripts. The client is a .NET Framework 4.8 Windows Forms program that shows one screen at a time in a WebBrowser control, loading it from this folder with a `file:///` URL. The program sets no Internet Explorer feature controls: there is no FEATURE_BROWSER_EMULATION entry, or any other FeatureControl entry, for it under HKEY_CURRENT_USER or HKEY_LOCAL_MACHINE. No Compatibility View settings, Internet Explorer group policies or Enterprise Mode site list applied, and the program does not customise the control beyond loading the page.

The workstations ran Windows 11 version 25H2 (build 26200) with the Internet Explorer 11 components that ship with it (MSHTML 11.1882.26100.0), en-US regional settings and the (UTC-05:00) Eastern Time (US & Canada) time zone with daylight saving time on.

Each entry was keyed in a freshly opened screen. The clerk filled in the controls and clicked Lodge entry, which ran the form's onsubmit handler once and submitted the form. Nothing else ran on the page in between. On every entry the handler ran to its end without a script error.

`journal.jsonl` has one JSON object per line and one line per entry. `entry` is the entry id, `screen` is the file name of the screen it was keyed on, and `keyed` maps the id of every keyed control, `txtRef` to `txaLines`, to the control's `value` as the browser reported it at the moment Lodge entry was clicked. Line breaks in the two text areas are given exactly as the control reported them, CR LF or LF. Invoice lines were pasted from spreadsheets, so their cells are separated by tabs.
